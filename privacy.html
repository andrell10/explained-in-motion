Privacy Policy

Last updated: November 16, 2026

"Explained in Motion Uploader" is a private tool used only by the owner of the YouTube channel Explained in Motion to publish videos to that channel. It is not offered to the public and no other users can sign in to it.

What data the tool uses

The tool uses the YouTube Data API to upload videos, set titles, descriptions, tags and thumbnails, and read basic information about the owner's own channel. It does not access any other user's data.

How data is stored

The access token is stored only on the owner's computer. No data is sold, shared with third parties or used for advertising.

Google and YouTube

The tool uses YouTube API Services. By using it you are also subject to the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google Account permissions.

Contact

Questions about this policy can be sent through the Explained in Motion YouTube channel.
